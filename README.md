# H.M.S. Home — Captain’s Bridge

Turn the whole house into a boat and lead the family on an indoor voyage.

H.M.S. Home is an iPad-first family game with a nautical house chart, selectable destinations, voyage events, meaningful crew choices, an engine telegraph, radar, ship’s horn, cabin lights, weather instruments, and a persistent captain’s log.

## How to play

1. Pick one of six ports on the Great Indoor Sea.
2. Cast off and set the engine telegraph.
3. Sail each passage and decide how the crew handles what happens.
4. Watch the ship’s condition, crew cheer, supplies, and route progress.
5. Reach port, sound the arrival horn, and begin another voyage.

Voyages are saved on the device, so an accidental reload does not send the ship back to harbor. Sound is optional, and the interface supports both portrait and landscape iPad play.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Then open the local address printed in the terminal.

## Verify a production build

```bash
npm test
```

The app is built with React, vinext, and Cloudflare-compatible server output. No accounts, location data, advertising, or personal household information are used.
